# Story campaign: everything to paste

The Story template is built in the panel's own form, not from an HTML file, so
this folder holds no HTML. It holds the exact values to type into each field and
the URLs of the artwork.

Artwork is committed at `cantu-pneus/en/images/story/` and generated by
`tools/assets/story.py`. Regenerate with `python3 tools/assets/story.py`.

- **5 story sets**, so five circles in the rail, which is what was asked for
- **11 slides** across them, 2 or 3 per set
- Covers are 312x312, cropped to a circle by the panel
- Slides are 1080x1920 portrait, and every one leaves its **lower fifth clear**
  so the panel's own CTA button has somewhere to sit

---

## Campaign and content settings

| Field | Value |
|---|---|
| Content name | `CantuPneus - Story Inline` |
| Campaign trigger | **Data Layer Event**, event name `story` |
| Select Website | `BR - cantu-pneus` (the one app guid for the whole origin) |
| Page | **On Different Page**, `/dengage-demos/cantu-pneus/en/` |
| Target Selector | `#dn_inline_target_below_header` |
| Mode | **Replace** |
| Web / Mobile Web | tick **both** |

The launcher's **Inline Scenarios** group on the English site has a
**Story (panel)** button that pushes `{ event: 'story' }`. It has no local
fallback on purpose, so if nothing appears the campaign is not live.

**Stories Title:** `Ready stock, line by line`

## Styles

| Setting | Value | Why |
|---|---|---|
| Stories Title colour | `#1A1030` | the site's ink |
| Stories Title size | 13 to 14px | it is a section label, not a heading |
| Stories Title weight | 700, uppercase if available | matches the site's `.text-label` |
| Stories Title alignment | left | the page is left-aligned throughout |
| Story item size | 68 to 74px | five fit a 390px phone without crowding |
| Border radius | 50% | circles, as in the reference |
| Border thickness | 3px | visible without dominating |
| Active border colour | `#FFE958` | brand yellow, an unread story |
| Passive border colour | `#D8D2E4` | grey, already seen |

## Two things worth knowing

**Per-line colours are deliberate.** The site is purple and yellow, but five
identical purple circles are hard to tell apart in a rail, so agricultural is
green, industrial rust and wheels blue while truck and passenger stay in the
purple family. If you would rather they were all brand purple, change the
`tint` values in `tools/assets/story.py` and regenerate; nothing else depends on
them.

**The slides carry no CTA button of their own.** The panel draws it from the CTA
fields, so a button baked into the image would double up. That is why the lower
fifth of every slide is empty.
